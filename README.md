# OSINT Self-Check

Бесплатные инструменты для **self-OSINT, privacy и anti-scam** проверки:

- возраст и регистрация домена (RDAP);
- DNS: A, AAAA, MX, NS, TXT;
- IP / ASN / сеть;
- проверка собственного публичного никнейма;
- чек-листы цифровой приватности;
- базовая проверка подозрительного сайта.

**Сайт:** https://fortnite26173-netizen.github.io/

> Используйте инструменты только для собственных данных, своей инфраструктуры
> или объектов, на проверку которых у вас есть разрешение.
